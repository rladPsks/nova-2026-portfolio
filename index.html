About us

실전형 에이전트 개발 팀

안전사고 데이터 위험도 분석, LLM Agent workflow, 근거 기반 RAG, 신뢰도 기반 예측까지 다양한 문제를 다뤘습니다. 서로 다른 프로젝트를 관통하는 관심사는 하나입니다. AI가 제한된 정보 속에서 무엇을 더 알아봐야 하는지 판단하고, 근거를 확인한 뒤 행동하게 만드는 것입니다.

01

Evidence Grounding

검색된 근거와 데이터 안에서 답하도록 범위를 제한하고, 출처와 검증 단계를 시스템에 포함합니다.

02

Adaptive Reasoning

고정된 질문 순서보다 현재 상태와 정보 부족 여부를 보고 다음 행동을 동적으로 결정합니다.

03

Uncertainty Aware

모델이 언제 확신할 수 있는지 정량화하고, 불확실할 때 추가 정보 획득 또는 안전한 보류를 선택합니다.

이 경험을 Doctor Agent로 확장합니다.

문진 → 진찰/검사 → 가설 갱신 → 근거 확인 → 종료 판단의 루프를 설계해, 제한된 턴 안에서 정확도뿐 아니라 정보 획득 효율성과 안전성까지 고려합니다.

ASK → EXAM / TEST → DIAGNOSE

이어지는 설계 관점

초기 정보만으로 결론을 서두르지 않고, 매 턴 가설과 불확실성을 갱신합니다. 후보 질환을 구분하는 데 가치가 큰 질문·진찰·검사를 선택하고, RAG로 의학적 근거를 확인하며, 충분한 근거가 모이면 탐색을 종료하는 구조를 지향합니다.

STATE증상·병력·검사 결과를 구조화해 누적
HYPOTHESIS진단 후보와 불확실성을 동적으로 갱신
SELECT후보를 가장 잘 구분할 다음 action 선택
GROUNDRAG로 의학적 근거와 판단을 연결
SAFETY모순·위험 신호·근거 부족을 별도 점검
STOP정보 가치가 낮아지면 탐색을 줄이고 진단
